## Tools for healthcare operations

At GEHA Health, I built Blazor and .NET tools that automated internal healthcare
workflows, turning operational data-processing needs into software capabilities.

I delivered C#, SQL Server, and Azure applications along with integration APIs
supporting the organization's software-service strategy and cloud-based data
workflows.

I also acted as a team lead, helping develop new internal tools for insurance
service staff working with customers by phone. I worked with the architecture
team on the database tables and API endpoints those tools needed.

## Telephone interactions

A phone-system project was at risk of missing its deadline. I had worked with
Avaya at the ticket company, so I reverse engineered the existing call workflow
and implemented the changes the business needed before the deadline. The work
used Java and Avaya to support the interactive voice response system.
