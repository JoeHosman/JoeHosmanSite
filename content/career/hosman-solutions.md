## Small engagements with specific problems

Hosman Solutions is my consulting company. The work has ranged from automating
repetitive browser tasks to translating data between formats and investigating
whether a hardware idea could work.

For a transportation company, I built a
[freight-bidding application](/projects/freight-bidding-automation/) in Python
and Selenium, with a web interface and Docker delivery. The client supplied the
workflow and proprietary calculation requirements.

For an airline employee, I built a
[C# bidding assistant](/projects/airline-bidding-assistant/) that watched for
preferred opportunities and kept the final decision with the person using it.

Another client needed [3D point data converted](/projects/point-data-converter/)
between two incompatible formats. I read the format documentation and built a
C# utility that bridged the gap until the original software gained the needed
export capability.

## Testing an idea's limits

Not every engagement became a finished product. For a
[camera inside a football](/projects/football-camera/), we built prototypes and
experimented with correcting the rotation in the video. We could improve the
footage with post-processing, but didn't achieve the required live result, and
the camera's weight changed how the ball handled.
