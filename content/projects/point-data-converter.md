## A missing connection

A client needed 3D point data converted from one format into another, and the
available software didn't provide the export they needed. I read the
documentation for both formats and built a C# conversion utility.

The tool served its purpose until the original application added the required
export format. At that point, the extra conversion step was no longer necessary.

This was a [Hosman Solutions](/career/hosman-solutions/) engagement with a
specific, limited job: make the existing tools work together.
